# Fuentes de datos

El dataset actual es local y minimo. No se hacen llamadas externas durante el uso de la app.

## Archivos

- `species.generated.json`: especies, nombres, grupos huevo, genero y linea base.
- `egg-groups.generated.json`: nombres de grupos huevo.
- `abilities.generated.json`: nombres de habilidades.
- `data-version.json`: version, procedencia y nota de licencia.

## Actualizacion futura

Se puede crear un script de desarrollo para regenerar JSON, pero el resultado debe quedar incluido en el repositorio. No deben incluirse sprites ni recursos oficiales sin licencia redistribuible.

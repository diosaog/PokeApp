# Modelo probabilistico

La herencia se calcula sobre patrones:

- Sin Lazo Destino: 3 estadisticas heredadas.
- Con Lazo Destino: 5 estadisticas heredadas.
- Los objetos recios fuerzan una estadistica segun el modo configurado.
- Los IV no heredados se modelan como uniforme 0..31 cuando el perfil lo permite.
